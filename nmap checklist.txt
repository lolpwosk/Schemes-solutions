Санирование:
192.168.1.1 - один айпи адрес
192.168.1.1-254 - диапазон
192.168.1.0/24 - подсеть

Фильтрация портов:

-p 80 - по номеру
-p http - по цифре
-p- все порты

Дополнение к опции -p:
можно указать порты UDP и TCP:
nmap -p U:53,11,123,T:80,22 -sS -sU
(но при такой комбинации обязательно указывать флаги вида сканирования (-sU, -sT, -sS), иначе сканирование работать не будет.

nmap -iL hosts.txt (скан хостов из файла)

nmap 192.168.1.0/24 --exclude 192.168.1.5 (исключение хоста)
nmap 192.168.1.0/24 --excludeFile exclude.txt (исключение хостов из файла)

nmap -sS айпи - SYN сканирование (без установления full TCP соединения)
nmap -sT айпи - (full tcp connect, для обхода блокировок сканирования)


Беспалевное сканирование:
nmap -p 80 -sT -Pn 10.129.8.147
(устанавливаем фулл соединение, без проверки доступности)

nmap -sU айпи адрес (UDP сканирование)

nmap -sA айпи адрес (ACK сканирование) - исп, если порт за брэндмауэром, просто ACK пакет

nmap -sF (Fin пакет)
nmap -sN (пустой пакет)
nmap -sX (FIN, PSH, URG) (аномальный пакет)

-T0 - -T5 - скорость сканирования, 0 - очень медленно, 2 - средне, 5 - очень много трафика.

-mtu - менять размер пакета. строго кратно 8

-O - определить версию ОС.
-sV - версию сервиса.

-A - (определение версии ОС, версий сервисов, сканирование со скриптами и трассировка маршрута)


--host-timeout <время h,m,s> - максимальное время для сканирования одного хоста,
по истечении которого, хост просто пропускается, никакой инфы не выводится.

--script-timeout <время h,m,s> - максимальное время, в течение которого скрипт может работать на целевом хосте.

-oA <имя (без расширения)> - сохранение результата в файл в нескольких форматах .nmap,gnmap,xml

nmap --script 'not brute' <айпи> сканирование всеми скриптами, кроме брутовых.

--open - покажет только открытые порты

Обход FW:
-f - дробит фрагменты по 8 байт.
-mtu <размер фрагмента, кратный 8> - произвольное задать размер фрагмента
--badsum - пакет с другой контролльной суммой
--source-port <port> скан с определенного порта. (сработает только при мисконфигурации fw)

TCP scan:
ответ SYN-ACK - порт открыт
ответ RST-ACK - порт закрыт
без ответа - порт за фаерволом.

UDP scan: 
Ответ в виде udp пакета - порт открыт.
