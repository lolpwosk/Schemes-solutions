FFUF дополнение:
Опции фильтрации: 
-fc <codes>, фильтрация по коду ответа, уберет ненужные
-fs <size>, фильтрация по размеру ответа, уберет ненужные
-fw фильтрация по кол-ву слов в ответе, можно указывать значение, значения через запятую, диапазон через тире.
-ft >100 - фильтрация по задержке ответа, покажется всё, что меньше 100 мс
-fr "word" - фильтр по слову, уберет ответы с указанным словом.

-mc - вывод только определенных кодов (и по аналогии)
Опции рекурсии:
-recursion - включает рекурсивный скан
-recursion-debth <число> (макс длинна вложенности, рекомендуется 2-3)

-rate <число> - ограничение числа запросов в секунду.

-o <файл> - запись результата в txt
-of all (все форматы)
-of html (записать результат в html)
-s - тихий режим (без прогресс бара)


фаззинг нескольких параметров.
ffuf -request reqq2 -request-proto http -w /home/kali/users:FUZZ -w /home/kali/pass:FUZZ2 -s
