Образ - код, библиотеки - нужно для работы контейнера.
Контейнер - запущенный экземпляр образа. Процесс, с собственным изолированным пространством файлов, сети, процессов.
volumes - тома, данные хранятся отдельно от контейнера. Директория на хост компьютере, которая монтируется внутрь контейнера.

sudo docker images - посмотреть список доступных на локальной машине образов.
sudo docker ps -a - посмотреть список всех контейнеров.


Загрузка образа:
docker search <имя> ищет образы в docker hub
docker pull <имя> - установить образ


docker run = docker create + docker start
sudo docker run <образ> - запустить контейнер из указанного образа


Пример:
docker run -d --name my-nginx -p 8080:80 nginx:alpine
(публикует порт на всех сетевых интерфейсах)
-d – запустить в фоне (detached)

--name my-nginx – дать понятное имя

-p 8080:80 – пробросить порт 8080 хоста на порт 80 контейнера (теперь http://localhost:8080 покажет Nginx)

--rm - автоматически удалять контейнер после его остановки.

sudo docker run -p 192.168.1.100:8080:80 nginx - привязка к определенному сетевому интерфейсу

sudo docker logs <имя контейнера> - смотреть все логи контейнера
sudo docker logs <имя контейнера> --follow смотреть логи в прямом эфире


Управление:
sudo docker stop my-nginx остановить контейнер
sudo docker start my-nginx запустить существующий контейнер снова.
sydo docker restart my0nginx

sudo docker exec -it my-nginx bash

docker rm my-nginx - удалить




docker compose - управление несколькими контейнерами сразу, зависит от конфигурационного файла .yaml, запускать утилиту строго в этой директории, где есть этот самый конфиг

docker compose up -d          # запустить все сервисы в фоне
docker compose logs -f        # посмотреть логи всех сервисов
docker compose ps             # статус контейнеров


docker build - команда используется для создания Docker образа на основе инструкций
из docker file.

синтаксис
docker build <опции> путь | URL

docker build -t my-app:v1 . - команда соберет образ с тегом v1, используя в качестве
контекста текущую директорию.
