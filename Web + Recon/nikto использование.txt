nikto -h <айпи/url> - базовое сканирование уязвимостей

nikto -h <айпи> -p 443 - сканирование с указанием порта

nikto -h <айпи> -p 443 -ssl 


nikto - исходя из чтения статей, сделал вывод, что это автоматизированный сканер уязвимостей веб приложений.
Можно проводить анонимное сканирование, используя tor, proxy.
Поддержка отчетов csv,json,html (смотреть в документации)


Использование, после основных опций:
-Format html -o <имя.html>

Содержит опцию -Tuning
означающую настройку сканирования

nikto -h <айпи> -Tuning x6 (просканит всеми тестами, кроме 6, который относится к DOS)

nikto -h <айпи> -Tuning 1248 (просканит только указанными)


Также есть опция -evasion, предназначенную для обхода IDS, посредством техник кодирования
Используется также по номерам
nikto -h <айпи> -evasion 12

-Pause <число> - опция для паузы между тестами, в секундах



Потенциальная команда: nikto -h https://asterit.ru/ -Tuning x6 -Format html -o asteritruscan.html

опционально:

-useragent "Mozilla/5.0...." - подмена User-Agent

-useproxy http://127.0.0.1:8080 - использование BURP, Tor
