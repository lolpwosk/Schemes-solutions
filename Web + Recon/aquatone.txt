cat <файл с адресами> | aquatone
cat <файл с адресами> | aquatone -nmap (из скана nmap)

-scan-timeout <мс>: Тайм-аут для сканирования портов (по умолчанию: 100 мс)
-screenshot-timeout <мс>: Тайм-аут для создания скриншотов (по умолчанию: 30000 мс)
-out <директория>: Указать папку для сохранения результатов (по умолчанию: текущая директория)
