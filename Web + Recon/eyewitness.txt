Eyewitness – инструмент, который делает скриншоты веб сайтов, генерит html отчеты
-f <файл> - указать файл со списком URL,nmap XML, Nessus XML
-x <файл.xml> - файл вывода.

--no-dns пропустить разрешение DNS

--timeout <sec> - макс время ожидания загрузки страницы
--delay <сек> - Задержка в секундах между открытием страницы и созданием скриншота
--jitter <сек>: Случайная задержка перед запросом для имитации человеческого поведения
--max-retries <число>: Количество повторных попыток при тайм-ауте

--user-agent "<строка>": Установить свой User-Agent для всех запросов
--proxy-ip <IP>: IP-адрес прокси-сервера
--proxy-port <порт>: Порт прокси-сервера
--proxy-type <тип>: Тип прокси (socks5 или http)

-d <директория>: Указать имя директории для сохранения отчета


--resume ew.db, чтобы продолжить работу с момента прерывания

Для опции -f <файл>
содержимое файла:
https://example.com
10.10.10.1:8080
https://192.168.1.1:8443
