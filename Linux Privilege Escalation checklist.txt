Доступны ли бинарники с SUID битом:
find / -perm -4000 -type f 2>/dev/null #смотреть на GTFOBins все бинарники
-4000 - SUID (вып программу от имени владельца) - исп.файлы
-2000 - SGID (вып программу от имени группы) - файлы/каталоги
-1000 Sticky Bit - каталоги - (нельзя удалять, переименновывать файлы)
0 - в контексте прав в опции -perm означает, что никаких требований.

Разведка:
find / -type f -perm -0002 2>/dev/null - файлы, доступные для записи всем
find / -type d -perm -0002 2>/dev/null - каталоги, доступные для записи всем.
find / -nouser 2>/dev/null - файлы без владельца (иногда остаются после удаления пользователей)
find / -group <группа> -ls 2>/dev/null - ищет файлы/каталоги, которые пренадлежат группе, выводит коману ls

На атакующем хосте:

Сгенерить ключ, подключиться по ssh:
на атакующем хосту генерим ключи
ssh-keygen -f isaac
Появляются 2 файла (private key и pub key)
pub key переносим на атакуемый хост в файл .ssh/authorized_keys, выдаем на него права chmod 600.
с атакуемого хоста:
выдаем chmod 600 на private key
подключаемся ssh user@host -i <private key>
