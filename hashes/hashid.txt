С помощью утилиты hashid можно определить разновидность хэша.
Использование и полезные опции:
hashid <хэш> - выведет возможные разновидности типа хэша
hashid <хэш> -e - выведет возможные разновидности типа хэша (включая хэши с солью, т.е больше вариаций)
hashid <хэш> -m (с mode для hashcat)
hashid <хэш> -j (с форматом для jtr)
-o FILE - сохраняет результат в заданный файл.
